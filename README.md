# K2 Auto Service

Premium automotive landing page built with Next.js and Tailwind CSS.

## Features

- Dynamic Hero section with scroll animations
- Strategic Vehicle Appraisal form
- Integrated contact system with Brevo
- Responsive design for all devices

## Getting Started

### Prerequisites

- Node.js 18+
- pnpm / npm

### Installation

1. Install dependencies:

    ```bash
    pnpm install
    ```

2. Set up environment variables:
   Create a `.env.local` file and add your Brevo API key:

    ```env
    BREVO_API_KEY=your_brevo_api_key_here
    ```

3. Run the development server:

    ```bash
    pnpm run dev
    ```

4. Build for production:
    ```bash
    pnpm run build
    ```
